# Washly 

A clean, mobile-friendly landing page for a local laundry pickup and wash service.

## Live Demo


## Overview
Washly is a lightweight front-end web page built for a doorstep laundry pickup service. It displays pricing, features, and a booking button — all in a single responsive HTML file with no dependencies.

## Features
-  Animated gradient background with floating bubble effects
-  Fully responsive — works on mobile and desktop
-  Clear pricing breakdown by clothing type
-  Service features section (pickup, delivery, wash & fold)
-  Direct booking via Google Form integration
-  Separate Q&A form for customer queries
-  Zero dependencies — pure HTML, CSS, and vanilla JavaScript

## Tech Stack
- HTML5
- CSS3 (animations, gradients, transitions)
- Vanilla JavaScript (dynamic bubble generation)
